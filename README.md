# 🔐 JavaScript Password Generator with Save

Web untuk generate password acak yang aman, dengan panjang yang bisa diatur sendiri dan bisa di-save jadi file `.txt`.

### ✨ Fitur
- Input custom panjang password
- Generate password acak (Huruf besar, kecil, angka, & simbol)
- Save password ke file `MyGeneratePasswordLOG.txt`
- UI clean pake Bootstrap 5

### 🛠️ Tech Stack
- HTML5
- Bootstrap 5.3.8
- JavaScript (Vanilla JS)

### 🚀 Cara Pakai
1. Isi `Panjang Password` misal `12`
2. Klik `Generate Password`
3. Klik `Save Password` buat download passwordnya
